# 点位与真实收益回放

用于用户反复要求“直接读 DC 消息、按点位和时间计算，不采用博主 R/pips”的场景。

1. 锁定频道授权、完整时间窗口、原始消息 ID 与时区；去重后恢复 entry/SL/TP、分批比例及移动保护的生命周期。
2. 区分原始信号、分钟 K 线理论触达、Paper 实际回执和 LIVE 真实净额。快照消失不是止损；无退出证据保持未解决，代理价格单列敏感性场景。
3. 统一仓位和资金口径；分别列手续费、滑点、资金费与缺失假设。净盈利/回撤/资金效率不能用胜率或博主宣称 R 替代。
4. 只在实际具备 entry、保护、成交/终态和成本证据时声明执行闭环。样本不足不能推出 LIVE-ready；不修库、不补单、不改 LIVE，除非另有精确授权。
5. 输出逐笔来源与不确定性台账，以及可重跑的现有项目脚本/测试位置。不将某次排名或日期数字写进长期规则。
